# PDF 서명·직인 스튜디오 (PDF Sign & Stamp Studio)

계약서에 도장 하나 찍자고 월 구독료를 내던 일을 없애는 **무서버 로컬 PDF 서명 도구**입니다.
PDF는 브라우저 메모리에서만 열리고, 서명·도장 이미지도 그 자리에서 만들어 PDF에 합쳐집니다.
파일 업로드 · 회원가입 · 건당 과금 · 워터마크가 모두 없습니다.

```bash
# 이 폴더를 정적 서버로 열기 (file:// 로 열면 글꼴·PDF 엔진 fetch가 막힙니다)
python3 -m http.server 8000
# → http://127.0.0.1:8000
```

GitHub Pages에 올리면 그대로 동작합니다(`.nojekyll` 포함). 배포 주소가 `marcj81.github.io/pdf-sign-stamp/`가
아니라면 `index.html`의 canonical·og:url·sitemap.xml 주소를 바꿔 주세요.

## 신뢰 설계 (서버 전송 0)

- 렌더링은 `pdf.js`, 편집·저장은 `pdf-lib` — 둘 다 `assets/vendor/`에 들어 있는 로컬 사본입니다. 외부 CDN 호출이 없습니다.
- 상단 배지의 **외부 요청 카운터**가 실제 네트워크 요청을 세어 0건임을 보여 줍니다.
- 문서·서명·도장은 `localStorage`에도 저장되지 않습니다(보관함에 저장한 서명·도장 PNG만 저장).
- 페이지를 닫으면 열었던 PDF는 메모리에서 사라집니다.

## 검증

```bash
node test.js          # 45 engine tests
python3 uitest.py     # 103 browser checks + 실제 PDF 파일 검증 + preview-*.png 캡처
```

`uitest.py`는 폴더를 HTTP로 띄우고 headless Chrome(`--no-sandbox`, 기동 재시도)을
1440×900과 390×844 두 뷰포트로 돌립니다. 확인하는 것:

- 첫 화면 · 배지 · 외부 요청 0건 · 콘솔/페이지 오류 없음
- 샘플 계약서 렌더링, 페이지 이동, 줌
- 서명 그리기 → 삽입 → 드래그 이동
- 직인 생성(투명 배경·붉은 잉크) → 삽입 → 모서리 크기 조절
- 텍스트 클릭 배치 → 속성 패널 수정 → 복제/삭제 → 실행 취소/다시 실행
- 다운로드한 PDF를 PyMuPDF로 열어 **A4 크기, 페이지 수, 한국어 본문, 삽입 이미지 수,
  서명·직인·텍스트의 좌표가 화면과 ±4pt 이내로 일치**하는지 확인
- 회전(90°)된 스캔 페이지에서도 스탬프가 페이지 안에 정확히 들어가는지
- 모바일 시트 UI와 모바일 다운로드

## 설계 메모

- **좌표계**: 화면은 pdf.js 표시 좌표(위가 0, y 아래로 증가), 저장은 PDF 좌표(아래가 0).
  페이지에 `/Rotate`가 걸려 있어도 `pagePointFromDisplay()`가 방향별로 변환하고,
  회전한 요소는 `elementTotalRotation()` + `displayAnchorToPage()`로 중심 회전을 재현합니다.
- **글꼴**: pdf-lib 1.17의 글꼴 서브셋 기능이 한글 글꼴에서 글리프를 깨뜨려(실측),
  Noto Sans KR을 한 번만 임베드(`subset:false`)합니다. 결과 PDF는 약 0.9MB가 늘지만
  본문·스탬프가 벡터 텍스트로 남아 인쇄 품질과 복사·검색이 유지됩니다.
  순수 ASCII 스탬프만 있을 때는 Helvetica를 써서 글꼴을 심지 않습니다.
- **미리보기 = 결과물**: 문서는 항상 pdf.js로 렌더링한 실제 PDF 위에 요소를 얹어 보여 주므로,
  화면에서 본 위치·크기가 그대로 파일에 들어갑니다(테스트가 ±4pt로 검증).
- **한글 금액**: 계약서·명세서에 `일금 일천이백만 원정` 표기를 자동 생성합니다(`amountInKorean`).

## 한계

- 본인확인·인증서 전자서명·공증·감사로그·발송 추적은 제공하지 않습니다(그 용도는 전자계약 서비스 영역).
- 기본 글꼴은 한글·영문·숫자·기호만 지원합니다. 한자·이모지는 입력 시 안내되고 저장에서 제외됩니다.
- 양식은 일반적인 예시이며 법률·세무 자문이 아닙니다.
